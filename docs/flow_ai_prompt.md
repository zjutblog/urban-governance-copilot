# 流程图 AI 生成提示词（Prompt 集）

> 目标：生成「城市治理 Copilot · 端到端闭环」流程图。
> **重要**：要文字准确的流程图，请用**图表类 AI**（boardmix AI / ProcessOn AI / Napkin AI / Eraser AI / Mermaid Chart AI）。
> 纯绘图模型（Midjourney / DALL·E / 即梦）画中文会乱码，只建议用来做**背景主视觉**（见第 4 节）。

## 0. 最佳路径（强烈推荐）
把项目里的 `docs/flow_vertical.mmd`（或 `docs/flow.mmd`）**整段 Mermaid 源码**贴进：
- **Mermaid Chart AI**（mermaidchart.com）——原生吃 Mermaid，字完全正确
- **boardmix AI / ProcessOn AI**——“用 Mermaid 生成流程图”入口
- **Eraser AI / Napkin AI**——可选文本描述或图表代码

生成后换个"科技蓝"主题、导出 SVG 即可。下面的提示词用于**没有 Mermaid 入口、只吃自然语言**的工具。

## 1. 主提示词（详细版，直接粘贴）

生成一张扁平化、科技政务风格的**端到端闭环流程图**，主题色为深蓝到亮蓝渐变，背景白色，圆角矩形，细线条，留白充足，无衬线中文字体，**所有中文标签必须清晰准确、不可乱码、居中对齐**。

**主链路**为 10 个节点，从左到右依次排列：
1. 「多模态输入」副标题：文本 / 现场图片
2. 「感知与诉求理解」副标题：分类 · 实体 · 地点 · 紧急度
3. 「知识检索」副标题：真实政策库 + 历史案例
4. 菱形判断节点「证据充分性？」副标题：自适应检索
5. 「空间分析」副标题：地点定位 + 邻近案例
6. 「智能分析」副标题：多源信息融合
7. 「决策建议」副标题：处置措施 · 责任部门 · 真实条款引用
8. 「质量门控」副标题：一致性投票 + 引用溯源 + 规则
9. 「交付」副标题：处理工单（完整率100%）+ 面向市民回复
10. 「人工复核 / 督办」副标题：采纳 · 修改 · 驳回

**连线规则**：
- 节点 1→2→3 依次用实线箭头连接；
- 节点 3→4；节点 4 分两条：一条虚线回到节点 3，标注「证据不足 · 换词再检索」；一条实线到节点 5，标注「证据充分」；
- 节点 5→6→7→8 依次实线连接；
- 节点 8 分三条：实线到节点 9 标注「pass 通过」；虚线回到节点 7 标注「retry 重写」；实线到节点 10 标注「escalate 一致性低」；
- 节点 9 实线到节点 10；
- 节点 10 用一条长虚线回到节点 2，标注「复核结果回流 · 数据飞轮」。

**审计留痕**：用一个浅蓝色大圆角外框把上述 1~10 号节点整体包住，外框顶部写「审计留痕 · 全链路 trace 落库（可回放 / 可审计）」，右下角小字标「端到端 < 30s（不含人工复核）」。

**工具与模型调用层**：在主链路下方单独一个横向浅灰圆角区域，标题「工具与模型调用层」，内含 6 张并列小卡片：
- 本地 BERT 分类器（感知分类，省 token）
- BM25 检索引擎（案例 33 万 / 政策 24 部·44 条款）
- 离线 geocoder（行政区划中心点表）
- MCP 模型工具（洪水 / 交通 / 生活圈）
- VLM 识图 kimi（现场照片 → 文本）
- 大模型 DeepSeek（分析 · 决策×3投票 · 回复）

并用**灰色虚线**从主链路中相关节点指向对应工具卡片（如：节点1→VLM识图、节点2→本地BERT、节点3→BM25、节点5→geocoder 与 MCP、节点6/7/8→DeepSeek）。

**配色语义（务必区分）**：
- 灰 = 输入 / 输出节点
- 青绿 = 本地 / 离线能力
- 青 = 检索
- 蓝 = 大模型
- 橙 = 规则 / 质量门控
- 紫 = 人工复核

节点内可配简洁线性图标（对话气泡、放大镜、数据库、大脑/齿轮、盾牌、文档对勾、地图、人形），图标单色、与节点主色一致。

## 2. 精简提示词（工具有长度限制时用）

画一张扁平科技蓝风格的政务系统流程图：主链路 10 个圆角节点从左到右——多模态输入 → 感知与诉求理解 → 知识检索 → 菱形判断「证据充分性？」 → 空间分析 → 智能分析 → 决策建议 → 质量门控 → 交付(工单+回复) → 人工复核；判断节点有一条虚线回退到知识检索(证据不足)，质量门控有三条分支(pass→交付 / retry→决策建议 / escalate→人工复核)，人工复核用虚线回流到感知节点(数据飞轮)。整条主链路用一个浅蓝外框包住，标题「审计留痕」。下方一排 6 个工具小卡：本地BERT、BM25检索、离线geocoder、MCP模型工具(洪水/交通/生活圈)、VLM识图kimi、大模型DeepSeek，用灰色虚线连到对应节点。配色：输入输出灰、本地青绿、检索青、大模型蓝、门控橙、人工紫。白底、圆角、细线、留白多、中文字体清晰不乱码。

## 5. 小贴士
